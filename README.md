# Student Performance Analytics – SQL Project

## Project Overview
This project focuses on analysing academic performance, student engagement and learning outcomes using MySQL. It integrates five interconnected tables: Students, Courses, Enrolments, Attendance and Assessments.

## Key Objectives
- Identify the top 10 students based on average assessment scores.
- Analyse course-wise academic performance and pass percentages.
- Identify students with attendance below 75%.
- Rank the top three students in each course.
- Identify students requiring academic intervention.
- Analyse the correlation between attendance and academic performance.
- Track improvements in student assessment scores.
- Create a comprehensive course performance leaderboard.

## Technical Skills Demonstrated
- MySQL Workbench
- Relational Database Management
- SQL Joins and Subqueries
- Common Table Expressions (CTEs)
- Window Functions: RANK(), LAG() and ROW_NUMBER()
- Aggregate Functions
- SQL Views
- Pearson Correlation
- Statistical and Exploratory Data Analysis

## Project Outcome
This project demonstrates how SQL and statistical techniques can transform educational data into meaningful insights, enabling educators to identify learning gaps, monitor student progress and support evidence-based academic decisions.
